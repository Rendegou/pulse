## 1. 纵深从哪来（游戏五件套，全部落地）

1. **多层视差**：云 0.25× / 远海远岛 0.45× / 中景波光 0.7× / 岛体 1× / 前浪 1.35×——拖拽平移时各层按比例错开，距离感是"动出来"的（验收已验证比例函数）。
2. **层叠遮挡**：岛是三层台地（顶台/草台/滩台），由远（上）到近（下）绘制，近层底部压过远层——参照《横版塞尔达》的台地层叠。
3. **大气透视**：三层台地按深度系数雾化（越高的层越远越淡），层与层之间压一条雾带；远景只用剪影。
4. **方向光与接地落影**：月光从左上，灯/树/台地都有同方向落影，物件被"钉"在各自台地上。
5. **尺寸与细节分级**：顶层小、雾、细节少；底层宽、清晰、细节多。

**贯穿元素的瀑布**从顶台沿崖面落到海面，把三层串成一条纵向轴线——纵深的"签名"。

## 3. 本轮验证

- `node --check`：内联脚本语法通过。
- 真实 Edge 无头 10 项检查通过（[work/floating-isle-validation.json](../work/floating-isle-validation.json)）：world 投影/锚定/拖拽；放大自动进入横版；**视差比例断言（岛 1.0 / 中景 0.7 / 远层 0.45 / 前浪 1.35）**；构图探针（岛台地带 58 vs 夜空 28）；灯面暖光探针；点灯阅读；Esc 返回；地点旅行确定性；明亮主题；窄屏无横向滚动并可进入点灯；减少动态。
- 截图带分析：天空 35（含月亮亮斑）→ 岛+雾带 62（画面最亮）→ 近海前浪 51——明暗三层分离，岛成为主体。
- 性能：world 首帧约 23ms（一次性）；横版每帧为若干层绘制 + 确定性枚举，无移动端/老设备实测。
- 本模型无法查看截图，画质以像素探针 + 交互断言验证；**审美仍需用户亲眼验收**。

## 4. 迁移计划（确认方向后）

1. `static/world.js`：world 俯瞰保留；新增 `side` 阶段（横版场景），替换 `PUBLICATION_PAGES` 相关绘制。
2. 数据模型：`Space { 台地参数, objects:[{type:'lantern'|'scroll'|'tree', tier, x, articleId?}] }`——台地层数与文章摆放即"自定义岛"的接口；将来服务端存储 + 作者身份 + 版本（路线 D）。
3. 流程沿用：选中 → 自动/按钮进入 → DOM 阅读 → 返回；i18n、明暗、键盘（方向键平移）、浏览器检查、性能报告。
4. 未测：真实触屏（拖动/双指缩放）、手机帧率、文章多于 5 篇的台地构图、多人同岛。
