## 如何判断你学会了

一项能力需要四份不同的证据：

- 能解释：不看答案说出输入、输出、谁调用、改了谁。
- 能实现：依据注释契约写出最小代码。
- 能验证：设计一个会暴露错误的反例，观察整条链路。
- 能迁移：隔一次练习，换一组数据或换一个事件独立完成。

不根据你说“感觉很弱”给能力定级。已经完成的代码值得保留；教程只通过短任务找出哪一环需要更多练习。
